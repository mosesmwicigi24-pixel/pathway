# Fonts for the Sunday Letter PDF

Static instances, fetched 2026-10-07 from Google Fonts. Each is licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org), which allows embedding in documents.

| File | Family | Licence |
|---|---|---|
| Fraunces-Regular.ttf, Fraunces-RegularItalic.ttf, Fraunces-SemiBold.ttf | Fraunces (Undercase Type) | OFL-1.1 |
| Inter-Regular.ttf, Inter-SemiBold.ttf | Inter (Rasmus Andersson) | OFL-1.1 |
| MrsSaintDelafield-Regular.ttf | Mrs Saint Delafield (Sudtipos) | OFL-1.1 |

They are embedded as subsets by `src/modules/intelligence/letterPdf.ts`, and match the
fonts the member apps use (Fraunces, Inter, and the signature face).
